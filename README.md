# Rouwan

간단한 습관 만들기 앱(Expo)

주요 기능
- 습관 추가(제목, 요일, 아이콘)
- 습관 체크(매일 완료 여부 기록)
- 주간/월간 통계(react-native-chart-kit)
- AsyncStorage 로컬 저장
- Expo Notifications 알림

설치

Windows(cmd)에서:

```
cd rouwan
npm install
npx expo start
```

(아래에 권장 패키지 설치 명령어가 있습니다.)
